# ⚡ 探索、影响分析与批量同步

MyKnownWorld 核心辅助认知功能深度说明。

---

### 1. 关系子图探索 (Graph Explorer)
支持以任意对象为中心节点，按指定方向（出向/入向/双向）和深度（1~5 层）展开星型拓扑图，并可多选谓词过滤。用于直观定位资产与外部系统之间的复杂引用网络。

### 2. 影响范围分析 (Impact Analysis)
当准备对某台机器下线或对某个微服务停机维护时，影响分析将自动从目标节点出发，仅沿着明确的运行（`hosts`）和依赖（`dependsOn`）链路计算波及资产，**严格排除弱知晓（`knowsAbout`）关系的干扰**。

### 3. 批量同步与可逆审计 (Sync & Batch)
支持外部来源批次导入。提交批次数据前必须先执行 `previewBatch` 得到原子变更 Diff 与指纹校验码，确认后再应用。每次应用都会记录版本哈希用于审计。撤回不通过接口提供：改动前请先备份数据库（见 scripts/backup-db.sh），业务删除采用逻辑删除（lifecycle 置 retired）。

---

## 常用操作快捷键

- `⌘ 1`：快速回到图谱总览；
- `⌘ K` 或顶部搜索框：全局实时模糊检索对象名称与唯一标识；
- `Esc`：一键关闭抽屉或弹出窗口。
