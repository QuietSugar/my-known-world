# 🛡️ 四大核心设计原则

贯穿 MyKnownWorld 架构与数据模型的不可逾越的设计红线。

---

### 1. 以 Self 为唯一锚点
系统不设虚无的“客观全局视角”，所有入图实体必须自 `Self`（我）出发保持弱连通。图谱中不存在无法追溯责任归属的无主孤岛。

### 2. 零明文秘密红线 (Zero-Secret)
图谱绝对严禁存录密码、SSH 私钥或 API Token 明文。`AccountCredential` 对象仅保留账号标识、授权范围及指向外部安全密码库（如 Vaultwarden / KMS / rbw）的指针引用。

### 3. 主观认知与影响隔离
严格区分“我负责维护（`maintains`）”与“我仅知晓（`knowsAbout`）”。弱知晓关系在故障与变更影响分析中自动隔离，避免告警泛滥。

### 4. 先预览后应用 (Dry-run First)
所有实体的新增、修改、废弃或批量导入均强制生成变更 Diff 预览（包含版本指纹验证），并在服务端记录可逆操作快照，支持无损回滚。
