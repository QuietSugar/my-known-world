# 🌿 定位与设计哲学

> **主观真实（Subjective Truth）**：准确表达已知，不臆测未知。

在现代工程基础设施中，传统的自动化扫描 CMDB 往往会抓取海量无主 IP、旁路服务与临时容器，带来极大的认知噪音与责任模糊。

**MyKnownWorld** 采取完全相反的哲学——**主观真实（Subjective Truth）**：
只记录**“我明确确认已知的事物”**，用确定性关系建立人与代码工程、部署实例、物理机器之间的责任链路。

---

## 为什么需要个人认知图谱？

1. **边界清晰的责任归属**：
   明确区分哪些资产属于我自主控制（`owns`），哪些由我主责维护（`maintains`），哪些仅是协作依赖（`uses`）或知晓（`knowsAbout`）。
2. **故障与变更影响可追溯**：
   通过严格的拓扑链路计算变更波及面，不传播弱知晓干扰，定位问题快、准、稳。
3. **人机协同的统一事实源**：
   不仅人类工程师可以通过 Web 界面交互，AI 编程助手（如 Cursor、Claude、Antigravity）也能通过原生的只读 MCP 协议随时向图谱检索上下文。
