# 🏢 CMDB 环境与资源映射

应用层 CMDB 与核心图谱的解耦设计与数据边界。

---

## 架构解耦原则

**CMDB 环境目录**维护在独立的应用层存储中，核心图谱仅通过节点 ID 进行引用，两者互不污染：

- **环境 (Environment)**：如 `env-prod-vpc`、`env-staging`，记录标签集合与网络边界。
- **服务 (Services)**：登记业务服务的逻辑标识与所属环境。
- **账户 (Accounts)**：登记环境绑定的外部鉴权引用，绝对不接收明文密码或私钥。

---

## 访问鉴权

访问 CMDB 目录要求提供独立的 `CMDB_APP_TOKEN`，令牌仅保存在当前浏览器 `sessionStorage` 中，关闭标签页即自动销毁。
