# 📂 项目工作区指南 (Project Workspace)

专为复杂交付项目设计的一站式聚合工作台。

---

在主页选择任意软件项目（如 `xasc`）后，点击 **「打开项目工作区」**，系统会自动沿图谱拓扑向下钻取，并聚合成四大核心视图：

### 1. 概览与关联依赖
展示代码库远程仓库地址、开发主语言、上游继任关系、当前项目关联的所有图谱拓扑边，以及关联的待办与重构事项（WorkItems）。

### 2. 部署与运行运维 (dcup 视图)
一目了然展示当前工程部署在各机器上的**实例列表（SoftwareInstance）**、端口、域名绑定以及底层**宿主机器（Machine）**详情。

### 3. 身份与凭据联动 (did 视图)
展示项目环境绑定的凭据元信息（AccountCredential），遵循零秘密原则，仅展示安全指针引用，保障生产敏感性。

### 4. 运维手册与文档 (Docs 视图)
集中汇总与此项目相关的重启、巡检、应急 Runbook 手册，以及交付规范与架构权威文档。
